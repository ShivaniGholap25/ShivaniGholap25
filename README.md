## 🚀 Featured Projects

### 🩰 [Nritya.ai: Bharatanatyam Exam Assistant](https://github.com/ShivaniGholap25/nritya-ai)

A **Retrieval-Augmented Generation (RAG)** assistant that answers Bharatanatyam theory questions from a textbook PDF in exam-style points.

- FAISS vector index for semantic search over the textbook
- FastAPI backend with web, Streamlit and CLI interfaces
- Offline mode using locally cached Hugging Face models

**Tech:** Python • FastAPI • LangChain • FAISS • Hugging Face • Streamlit

---

### 🛡️ [Job Guard: Fake Job Offer Detector](https://github.com/ShivaniGholap25/job-guard-ai-extension)

A **Chrome extension** that analyses job postings in the browser and shows a scam-risk score in real time.

- FastAPI REST endpoints for analysis, risk scoring and explanations
- Groq LLM API to classify suspicious postings and detect scam indicators

**Tech:** FastAPI • Groq API • Chrome Extension • JavaScript

---

### 🏥 [Smart Clinic Management System](https://github.com/ShivaniGholap25/Smart-Clinic) | [Live Demo](https://smart-clinic-henna.vercel.app)

A web-based clinic system to manage patient records and appointments.

- Flask backend with MySQL for secure CRUD operations
- Responsive interface for an efficient healthcare workflow

**Tech:** Python • Flask • MySQL • HTML • CSS
